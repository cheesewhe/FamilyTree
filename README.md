# Семейное древо Тимофеевых и Воронцовых

Статический сайт: обычные HTML-файлы, без сборки.

**Сайт в интернете:** https://cheesewhe.github.io/FamilyTree/ (GitHub Pages из ветки `main`).

## Как открыть

Двойной клик по `index.html` тоже работает, но интерактивное древо (поиск, фильтры,
перетаскивание) браузер блокирует для адресов `file://`. Поэтому лучше запускать через
локальный сервер из этой папки:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Главная: фото, ближайшие даты, цифры, карточки разделов |
| `drevo-semi.html` | Интерактивное древо (показывает `Timo-Family.html`) и круговая схема предков |
| `Timo-Family.html` | Выгрузка древа из Genery. **Рядом должна лежать папка `Timo-Family.html.files`** с фото и карточками людей. Сейчас её нет. |
| `timofeevy.html`, `vorontsovy.html` | Линии отца и мамы |
| `kalendar-dat.html` | Календарь памятных дат |
| `100-russkiy.html` | Главы книги «100%-ный русский» |
| `dokumenty-i-arhivy.html`, `karta-obitaniya-predkov.html`, `k-80-letiyu-pobedy.html`, `blog-novosti.html`, `dnk-genealogiya.html` | Остальные разделы |
| `site.html`, `osnovnaya-stranica.html` | Старые адреса, перенаправляют на `index.html` |
| `assets/css/site.css` | Дизайн-система «Семейный архив»: цвета, шрифты (Old Standard TT и Golos Text), все компоненты |
| `assets/js/tw-config.js` | Цвета Tailwind для страницы древа под общую палитру |
| `assets/js/site.js` | Общий скрипт: **меню и каталог разделов** (`SECTIONS`), **памятные даты** (`FAMILY_DATES`), **лента поколений** на главной (`MILESTONES`) |
| `assets/img/` | Картинки |
| `_архив/` | ТЗ (xlsx), старый макет `testoviy.html`, zip-архив, копия сайта до наведения порядка и копия до редизайна |

## Как добавлять

- **Памятную дату** — строкой в `FAMILY_DATES` в `assets/js/site.js`. Она сразу появится
  в календаре и в блоке «Ближайшие даты» на главной.
- **Новый раздел** — скопируйте любую страницу раздела, поменяйте заголовок и текст,
  затем добавьте строку в `SECTIONS` в `assets/js/site.js`. Меню на всех страницах обновится само.
- **Обновлённое древо** — замените `Timo-Family.html` и папку `Timo-Family.html.files`.

## Как обновить сайт в интернете

После любых правок в этой папке отправьте их на GitHub — через минуту-две сайт обновится сам:

```bash
git add -A
git commit -m "Что изменилось"
git push
```

Репозиторий публичный: всё, что лежит в этой папке (в том числе `_архив`), видно любому по ссылке.
